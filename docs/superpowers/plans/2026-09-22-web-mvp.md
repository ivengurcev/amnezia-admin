# Amnezia Admin Web MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive Russian-language React administration page for listing and managing AWG peers, including one-time configuration download after creation.

**Architecture:** Add a new `@amnezia-admin/web` Vite workspace. Keep HTTP and response parsing in `api.ts`, page-level collection state in `App.tsx`, and mutation state inside focused form/row components; use relative `/api` requests with a development proxy to port 3001.

**Tech Stack:** React 19, TypeScript 6, Vite 5, ordinary CSS, Vitest 2, jsdom, Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-22-web-mvp-design.md`

## Global Constraints

- Use React, TypeScript, Vite, and ordinary CSS; do not add a UI library or state manager.
- All visible interface text is Russian except the product name “Amnezia Admin” and protocol metrics RX/TX.
- Browser requests use relative `/api/...` paths; Vite proxies `/api` to `http://localhost:3001`.
- Do not modify the backend unless a verified integration defect makes it necessary.
- Never persist, log, or render the POST response's `privateKey` or `config`.
- Do not implement QR codes, authentication, deep links, repeat config downloads, AWG settings, charts, themes, i18n, or WebSockets.
- Use strict TypeScript, ESM, and four-space indentation.
- Do not create git commits or push; replace plan commit checkpoints with status/diff checks.

## Review Focus

- A network rejection must become a readable Russian error rather than an unhandled promise rejection; covered in Task 1 API tests.
- A non-JSON error response must fall back to an HTTP-status message; covered in Task 1 API tests.
- Unsafe filename characters in a peer name must not escape into the downloaded filename; covered in Task 3 creation tests.
- Cancelling the delete confirmation must not send a DELETE request; covered in Task 4 row tests.
- An invalid handshake timestamp must render as “Нет данных” rather than “Invalid Date”; covered in Task 2 formatter tests.

Create `packages/web/src/api.ts`:

```typescript
export type Peer = {
    id: string | null;
    publicKey: string;
    name: string;
    address: string;
    connected: boolean;
    latestHandshakeAt: string | null;
    rxBytes: number;
    txBytes: number;
};

export type CreatedPeer = {
    id: string;
    publicKey: string;
    name: string;
    address: string;
    privateKey: string;
    config: string;
};

export class ApiError extends Error {
    constructor(message: string, readonly status?: number) {
        super(message);
        this.name = 'ApiError';
    }
}

async function request<T>(
    path: string,
    options?: RequestInit,
): Promise<T> {
    let response: Response;

    try {
        response = await fetch(path, options);
    } catch {
        throw new ApiError('Не удалось связаться с сервером');
    }

    if (!response.ok) {
        const body: unknown = await response.json().catch(() => null);
        const message = body && typeof body === 'object' &&
            'error' in body && typeof body.error === 'string'
            ? body.error
            : `Ошибка сервера (HTTP ${response.status})`;

        throw new ApiError(message, response.status);
    }

    if (response.status === 204) {
        return undefined as T;
    }

    try {
        return await response.json() as T;
    } catch {
        throw new ApiError('Сервер вернул некорректный ответ');
    }
}

const jsonHeaders = { 'content-type': 'application/json' };

export function listPeers(): Promise<Peer[]> {
    return request<Peer[]>('/api/peers');
}

export function createPeer(name: string): Promise<CreatedPeer> {
    return request<CreatedPeer>('/api/peers', {
        method: 'POST',
        headers: jsonHeaders,
        body: JSON.stringify({ name }),
    });
}

export function renamePeer(id: string, name: string): Promise<void> {
    return request<void>(`/api/peers/${id}`, {
        method: 'PATCH',
        headers: jsonHeaders,
        body: JSON.stringify({ name }),
    });
}

export function deletePeer(id: string): Promise<void> {
    return request<void>(`/api/peers/${id}`, { method: 'DELETE' });
}
```

- [ ] **Step 3: Implement formatters**

Create `packages/web/src/format.ts` with binary units `Б`, `КБ`, `МБ`, `ГБ`, and `ТБ`, one decimal place only when needed, and a `ru-RU` `Intl.DateTimeFormat` for handshake values. Return `Нет данных` when the value is null or parses to an invalid date.

```typescript
const byteUnits = ['Б', 'КБ', 'МБ', 'ГБ', 'ТБ'];
const dateFormatter = new Intl.DateTimeFormat('ru-RU', {
    dateStyle: 'short',
    timeStyle: 'medium',
});

export function formatBytes(bytes: number): string {
    if (bytes <= 0) {
        return '0 Б';
    }

    const unitIndex = Math.min(
        Math.floor(Math.log(bytes) / Math.log(1024)),
        byteUnits.length - 1,
    );
    const value = bytes / 1024 ** unitIndex;

    return `${new Intl.NumberFormat('ru-RU', {
        maximumFractionDigits: 1,
    }).format(value)} ${byteUnits[unitIndex]}`;
}

export function formatHandshake(value: string | null): string {
    if (!value) {
        return 'Нет данных';
    }

    const date = new Date(value);
    return Number.isNaN(date.getTime())
        ? 'Нет данных'
        : dateFormatter.format(date);
}
```

```typescript
function safeConfigFilename(name: string): string {
    const safeName = name
        .replace(/[\\/:*?"<>|]+/g, '-')
        .replace(/\s+/g, '-')
        .replace(/-+/g, '-')
        .replace(/^-|-$/g, '');

    return `${safeName || 'amnezia-peer'}.conf`;
}

function downloadConfig(name: string, config: string): void {
    const url = URL.createObjectURL(new Blob([config], {
        type: 'text/plain;charset=utf-8',
    }));
    const link = document.createElement('a');
    link.href = url;
    link.download = safeConfigFilename(name);
    document.body.append(link);
    link.click();
    link.remove();
    URL.revokeObjectURL(url);
}
```

The form state contains only `name`, `submitting`, and `error`. On success call `downloadConfig(peer.name, peer.config)`, clear the input, then await `onCreated()`. Never set the created peer, `config`, or `privateKey` into React state.
