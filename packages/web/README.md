# React-админка AmneziaWG

Сборка из корня: `yarn workspace @amnezia-admin/web build`.
Проверки: `yarn workspace @amnezia-admin/web typecheck` и
`yarn workspace @amnezia-admin/web test`.
Vite используется для сборки; запуск отдельного frontend HTTP-сервера не требуется.

`Dockerfile.cpp` собирает `packages/web/dist` в этапе `web-builder` и копирует
его в `/app/web` C++ runtime. Node.js, Yarn и Vite не копируются в runtime.
C++ административный сервер отдаёт `/app/web` и `/api` с одного origin.
Существующие cookie-сессии и маршруты `/api/auth/login`, `/api/auth/me`,
`/api/auth/logout` сохранены; токены не хранятся в localStorage.

## Контракт подключений

- `GET /api/peers`: массив `{ publicKey, name, allowedIps, isAdmin, endpoint,
  latestHandshake, rx, tx }`. `endpoint` — строка или null, handshake — Unix
  seconds (0 означает отсутствие), rx/tx — байты. Идентификатор — publicKey.
- `POST /api/peers`: JSON `{ name }`, ответ содержит publicKey и allowedIps.
- `POST /api/peers/links`: JSON `{ publicKey, ttlSeconds: 86400 }`, ответ `{ url }`.
- `DELETE /api/peers`: JSON `{ publicKey }`, успешный ответ 204.

Статус вычисляется в браузере: handshake от 0 до 180 секунд назад включительно
означает «Подключён». Нулевой, некорректный и будущий timestamp не считается
подключением. Статус пересчитывается раз в секунду без дополнительных запросов;
новые метрики загружаются кнопкой «Обновить».
Создание и выпуск ссылки — отдельные операции. При ошибке второй операции
повторяется только выпуск ссылки, подключение повторно не создаётся.
Скачивание .conf и переименование в административном интерфейсе отсутствуют.
Clipboard API требует защищённый контекст (HTTPS или localhost); при его
недоступности ссылка остаётся в поле для ручного копирования.

## Интеграция с C++

`POST /api/peers` принимает имя, обрезает пробелы по краям и сохраняет его.
Имя необязательно: пустая строка разрешена, а в списке вместо неё отображается
VPN-IP. Фронтенд ограничивает имя 100 символами, backend — 400 байтами UTF-8.
Ответ создания содержит `publicKey`, `allowedIps` и `name`; приватный ключ
не передаётся административному клиенту.

Публичный сервер обслуживает `/setup/:token` и два CSS-ресурса:

| URL | Файл в runtime |
| --- | --- |
| `/assets/theme.css` | `/app/web/assets/theme.css` |
| `/assets/setup.css` | `/app/web/assets/setup.css` |

Vite копирует их из `public/assets` в `dist/assets` без хеша. C++ HTML
подключает оба файла без встроенных стилей, React и административного JS.
Административная статика отдельно смонтирована из `/app/web`.

Development-окружение C++ запускается через `compose.cpp.yml`, production —
через `compose.prod.yml`. Оба используют C++-сервер; Node.js нужен только
на этапе сборки фронтенда.

Общие дизайн-токены находятся только в `public/assets/theme.css`.
Компонентные стили — CSS Modules; `src/styles.css` содержит глобальный reset.

## Управление размерами

В `public/assets/theme.css` достаточно менять базовые значения:

- `--font-size: 1em` — базовый размер шрифта страницы.
- `--type-scale: 1.125` — соотношение размеров текста.
- `--spacing: .5em` — плотность: отступы, размеры кнопок/иконок, обводки и тени.
- `--radius: .5em` — скругления.
- `--content-width: 74em` — предельная ширина; ширины формы входа и модального
  окна рассчитываются от неё.

Остальные размеры вычисляются через `calc()`. Нумерованной шкалы `space-*` нет.
Размеры заданы в `em` и масштабируются со шрифтом; проценты и единицы viewport
остаются для ограничений по экрану. Медиазапросы тоже в `em`; CSS-переменные
в условиях медиазапросов не поддерживаются, поэтому пороги указаны там явно.

## Управление цветами

Базовая палитра в `public/assets/theme.css` содержит пять цветов:
`--palette-light`, `--palette-dark`, `--palette-accent`, `--palette-danger`,
`--palette-success`. Остальные цвета — семантические ссылки на палитру или
`color-mix(in srgb, ...)`: поверхности, границы, приглушённый текст, hover,
фокус, затемнение модальных окон и тени. Изменение базового цвета автоматически
обновляет зависимые оттенки в админке и публичной странице. Используется
нативный CSS `color-mix()`, требующий поддержки браузером.
